# SmartAttend AI

AI-powered attendance management system built on ServiceNow with dynamic QR attendance, kiosk validation, Now Mobile, approval workflows, shift management, and Gemini AI insights.

## Overview

SmartAttend AI is a ServiceNow-based attendance platform designed for secure employee attendance, manager visibility, and AI-assisted attendance analysis.

The solution uses short-lived QR codes generated by employees, verified through a registered kiosk, and processed through ServiceNow Scripted REST APIs.

## Key Features

- Single-use anti-replay validation
- Registered kiosk scanning

## Dynamic QR Attendance Flow

1. Employee logs into Now Mobile.
2. Employee generates a short-lived QR code.
3. A registered kiosk scans the QR.
4. Backend validates:
   - token status
   - expiry
   - kiosk registration
   - employee profile
   - assigned shift
5. Attendance is recorded.
6. QR token is marked as used.
7. Replay attempts are rejected.

## Attendance Correction Workflow

1. Employee selects an attendance record.
2. Employee submits a correction request.
3. ServiceNow Flow Designer routes the request to the employee’s manager.
4. Manager reviews the request through native Approvals.
5. If approved, the attendance record is updated.
6. Employee can view the completed correction request in Now Mobile.

## Shift Management

Managers can:

- Create new shifts
- Configure start and end time
- Configure grace period
- Configure full-day and half-day thresholds
- Assign shifts to managed employees

## AI Attendance Insights

SmartAttend AI integrates Gemini to generate manager-focused attendance summaries based only on verified attendance statistics.

The AI is restricted to:

- Attendance observations
- Pattern detection
- Schedule review recommendations
- Verification suggestions
- Non-disciplinary manager follow-up

The AI does not make employment decisions.

## Security

- Role-based ACLs

- Registered kiosk validation
- Token expiration
- Single-use QR tokens
- Employee ownership validation

- Server-side API validation

## Setup

To deploy the project on another ServiceNow instance:

1. Import or connect the application using ServiceNow Source Control.
2. Create the required SmartAttend users and roles.
3. Configure employee profiles and shifts.
4. Register a kiosk user and scanner.
5. Create a Global system property:

`smartattend.gemini_api_key`

6. Store the Gemini API key in that property.
7. Configure Now Mobile navigation and access.
8. Test QR generation, kiosk scan, correction workflow, and AI insights.

Never commit the actual Gemini API key to GitHub.
